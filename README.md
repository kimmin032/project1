# A/B 마케팅 문구 생성기

## 1) 목적과 사용자

상품 설명과 타깃 페르소나를 입력하면 A/B 테스트용 마케팅 문구 2안을 만들어 주는 Streamlit 앱입니다.
마케팅 전담 인력이 없는 소규모 쇼핑몰 셀러가 사용자입니다.

## 2) 실행 방법

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # 열어서 OPENROUTER_API_KEY에 본인 키 입력
streamlit run app.py
pytest                      # 테스트 실행 — 테스트 108개 통과 (2026-10-20 직접 실행해서 확인)
```

- `OPENROUTER_API_KEY`: OpenRouter에서 발급받은 키를 `.env`에만 적습니다. 커밋하지 않습니다.
- `OPENROUTER_MODEL`: 사용할 OpenRouter 모델 ID입니다. 비워 두면 기본 무료 모델(`nvidia/nemotron-3-super-120b-a12b:free`)을 씁니다.

## 3) 주요 기능 3가지

1. **A/B 2안 생성**: A안은 가격·혜택, B안은 페인 포인트 공감으로 소구점을 고정하고, 두 안 모두 2~3문장으로 씁니다.
2. **채널별 버전과 글자 수 검사**: 카톡 본문, 인스타 헤드라인·본문, 이메일 제목을 함께 만들고 글자 수를 보여줍니다. 한도를 넘으면 자르지 않고 경고만 합니다. 이메일 제목 앞의 "(광고) "는 코드가 붙입니다.
3. **입력 검증과 세부 설정**: 설명이 너무 짧거나 기호뿐이거나 비어 있으면 AI를 부르지 않고 안내합니다. 페르소나를 고르지 않으면 기본값이 적용됩니다. 프레임워크(자동/AIDA/PAS)를 고를 수 있고, 각 안의 CTR 가설도 보여줍니다.

## 8) 한계점

- 무료 모델을 쓰므로 응답 품질과 속도가 모델과 OpenRouter 상태에 따라 달라집니다.
- 인스타 헤드라인(30자)과 이메일 제목(40자) 한도는 임시값입니다. 카톡 본문(400자)만 출처를 확인했습니다.
- 글자 수 한도는 프롬프트로 요청할 뿐 AI가 지킨다고 보장하지 못하며, 넘으면 경고만 표시합니다.
- 상품 설명에 없는 사실을 지어내지 않는 규칙도 프롬프트로만 요청하고, 코드로 검증하지는 않습니다.
- 결과는 저장하거나 내보낼 수 없고 화면 세션 동안만 유지됩니다.
- 화면 장식용 캐릭터 그림은 로컬 전용이라 저장소에 없으며, 없으면 이모지로 대체됩니다.
- 직접 테스트하며 발견한 점:
  - AI가 입력에 없는 혜택이나 금지어("완벽히", "세련된", "최강")를 지어내기도 합니다.
  - 가끔 영어 단어("bulky")가 섞이고, 말투가 페르소나보다 딱딱합니다.
  - "USB 3.0"처럼 글자가 5개보다 적은 짧은 상품명은 너무 짧다고 막힙니다.
  - 기본 무료 모델(nemotron)은 한 번에 약 4분 30초가 걸립니다. gpt-4o-mini는 빠르지만 규칙을 더 자주 어깁니다.
  - 테스트한 상품 수가 적어서 결과를 일반화하기 어렵습니다.

## 9) 핵심 소스 파일

| 파일 | 설명 |
|---|---|
| `app.py` | Streamlit 화면 흐름(입력, A/B 결과, 채널 버전, CTR 가설) |
| `generator.py` | `generate()`: 입력 검사 → AI 호출 → JSON 해석 → 글자 수 검사 |
| `prompts.py` | 프롬프트, 페르소나·프레임워크·채널 글자 수 한도 |
| `llm_client.py` | OpenRouter 호출, 모델·키 설정 |
| `input_check.py` | 입력 검증 규칙 |
